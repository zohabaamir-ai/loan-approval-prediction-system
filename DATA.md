# Data

## Source

The project uses the Kaggle dataset titled **"Loan Approval Classification Dataset"**: 45,000 rows and 14 columns about loan applicants. The dataset's description states that it is synthetic, generated from a credit-risk dataset. It was not created by the author of this repository.

## License

The license of this dataset has **not been verified** by the author of this repository, so the file is **not redistributed here** (`data/loan_data.csv` is excluded by `.gitignore`). Check the license on the dataset's Kaggle page before reusing or redistributing it.

## How to get it

1. Create a free Kaggle account and search for **Loan Approval Classification Dataset**.
2. Download it and unzip it.
3. Copy `loan_data.csv` into this repository's `data` folder, so the path is `data/loan_data.csv`.
4. Check that it is the right file:

```powershell
python -c "from loan_approval.data import load_data; print(load_data().shape)"
```

The expected output is `(45000, 14)`.

## Columns

| Column | Meaning |
|---|---|
| `person_age` | Applicant age in years |
| `person_gender` | female or male (not used by the final model) |
| `person_education` | High School, Associate, Bachelor, Master or Doctorate |
| `person_income` | Yearly income (currency not stated) |
| `person_emp_exp` | Years of employment experience |
| `person_home_ownership` | RENT, OWN, MORTGAGE or OTHER |
| `loan_amnt` | Loan amount requested |
| `loan_intent` | EDUCATION, MEDICAL, VENTURE, PERSONAL, DEBTCONSOLIDATION or HOMEIMPROVEMENT |
| `loan_int_rate` | Interest rate in percent |
| `loan_percent_income` | Loan amount divided by income |
| `cb_person_cred_hist_length` | Credit history length in years |
| `credit_score` | Credit score |
| `previous_loan_defaults_on_file` | Yes or No |
| `loan_status` | Target: 1 = approved, 0 = rejected (per the dataset description) |

## What this repository does to it

- No missing values and no duplicate rows were found.
- 7 rows with an age above 100 are removed, leaving 44,993 rows.
- A stratified 80/20 split with seed 42 gives 35,994 training rows and 8,999 test rows.

## What is in the repository instead

`data/sample_synthetic.csv` is a small **fake** dataset (600 random rows with the same columns), generated by `python -m loan_approval.synthetic`. It exists only so that the tests and CI can run without the real data. It carries no real signal, and no result should ever be reported from it.

## Quirks worth knowing

- The label is the historical decision in the data, not whether the borrower repaid.
- Every applicant with `previous_loan_defaults_on_file = Yes` is rejected.
- Larger loans at higher interest rates tend to be approved, which is the opposite of real lending logic and is most likely an artifact of how the data was generated.

See the "Fairness and limitations" section of the [README](README.md) for how these affect the results.
